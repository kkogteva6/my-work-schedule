# Мой график

Небольшое приложение для iPhone в формате PWA (устанавливаемое веб-приложение). Оно работает как отдельная иконка на домашнем экране, открывается без панели браузера и после первого запуска может работать без интернета.

## Что уже умеет

- рабочая норма Пн–Чт: 9:00, пятница: 7:45
- автоматический расчёт времени нормального ухода от времени прихода
- баланс `+ / −` по каждому дню и за расчётный период
- расчётный период по умолчанию: с 20-го числа по 19-е следующего месяца
- просмотр прошлых расчётных периодов
- быстрые кнопки «Я пришла» и «Я ушла»
- расчёт раннего ухода с учётом уже накопленного баланса
- поле «быть там к» + время дороги → автоматический расчёт, когда уйти с работы
- недельные планы с галочками; список дел сохраняется, а отметки выполнения начинаются заново каждую неделю
- резервная копия в JSON и восстановление из неё
- настройки нормы, границ рабочего дня, даты начала периода и времени дороги
- офлайн-режим после первого открытия

## Почему PWA, а не обычное приложение из App Store

Для личного приложения это самый простой вариант, особенно если основной компьютер — Windows. Не нужен Mac, Xcode и платная публикация в App Store. После размещения файлов на HTTPS-сайте iPhone позволяет добавить приложение на домашний экран и открывать его как отдельное приложение.

## Как установить на iPhone

Сначала проект нужно разместить в интернете по HTTPS. Подойдут, например, GitHub Pages, Netlify или Cloudflare Pages.

После публикации:

1. Открой ссылку **именно в Safari** на iPhone
2. Нажми кнопку «Поделиться»
3. Выбери «На экран Домой» / Add to Home Screen
4. Включи «Открывать как веб-приложение», если iPhone показывает этот переключатель
5. Нажми «Добавить»

На домашнем экране появится иконка «Мой график».

## Вариант через GitHub Pages

1. Создай новый репозиторий, например `my-work-schedule`
2. Загрузи в корень все файлы из этой папки, включая папку `icons`
3. В GitHub открой `Settings → Pages`
4. В разделе публикации выбери ветку `main` и папку `/ (root)`
5. После публикации GitHub покажет HTTPS-ссылку
6. Открой её на iPhone и добавь на домашний экран по инструкции выше

## Где хранятся данные

В этой версии всё хранится локально на устройстве в хранилище веб-приложения. Сервер и аккаунт не нужны. Поэтому периодически открывай настройки и нажимай «Скачать копию».

Если позже понадобится синхронизация между iPhone и компьютером, можно добавить вход в аккаунт и облачную базу данных.

## Файлы проекта

- `index.html` — интерфейс
- `styles.css` — оформление и адаптация под iPhone
- `app.js` — расчёты, периоды, планы, сохранение данных
- `manifest.webmanifest` — параметры установки на домашний экран
- `sw.js` — офлайн-кэш
- `icons/` — иконки приложения
